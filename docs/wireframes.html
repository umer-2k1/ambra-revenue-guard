Component map (shadcn/ui)

Card / CardHeader / CardContent — stats, rule & flag panels
Table — denials list
Badge — severity, payer, outcome, CPT/CARC (+ custom variants)
Button — pill CTA variants (primary dark, accent orange, outline)
Tabs — the 4-screen navigation
Progress — analysis bar
ScrollArea — SSE live feed, long rule list
Alert — risk flags, success + empty states
Select — service / payer / CPT dropdowns
Textarea — PCR narrative input
Skeleton — loading while the LLM thinks
Tooltip — CARC/CPT hints, truncated text

Icons: lucide-react (Brain, ShieldCheck, AlertTriangle, CheckCircle, Loader2, RefreshCw).
