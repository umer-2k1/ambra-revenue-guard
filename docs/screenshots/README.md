## How to capture

1. Run the app (`http://localhost:5173`) or use the live demo (`https://ambra.umer2k1.com`).
2. Set the window to ~1440px wide.
3. Screenshot just the content area (avoid browser chrome), then save here.

Naming matters — the README references these exact files.
